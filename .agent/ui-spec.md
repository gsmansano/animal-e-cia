# Animal & Cia - UI & Content Specification

## Architecture
- **Type:** Single-page application
- **Navigation:** Sticky header with anchor jump links (e.g., `#servicos`, `#sobre`, `#localizacao`, `#contato`).

## Brand Tokens
- **Primary Action (Pink):** `#EA005E`
- **Headings/Text (Dark Green):** `#1A5A29`
- **Accents (Light Green):** `#8CC63F`

## Typography
- **Headings:** Barlow
- **Body:** Montserrat

---

## Section Blueprint (Top to Bottom)

### 1. Header
- **Behavior:** Sticky (transparent-to-solid on scroll).
- **Left:** Logo placeholder.
- **Center:** Jump links (`#servicos`, `#sobre`, `#localizacao`, `#contato`).
- **Right:** WhatsApp CTA button.

### 2. Hero
- Brief welcome messaging.
- Image carousel / placeholder.
- Primary WhatsApp CTA button.

### 3. Services (`#servicos`)
- Visual grid detailing core offerings:
  - Consultations
  - Blood Exams
  - Ultrasound (USG)
  - X-Ray
  - Surgeries
  - ICU
  - Pharmacy/Shop items

### 4. About Us (`#sobre`)
- Vet history and background.
- Clinic expansion context.
- Team photos.

### 5. Location (`#localizacao`)
- Brumado context.
- Embedded Google Maps iframe.
- Direct "Get Directions" map link button.
- Operating hours.

### 6. Contact & Footer (`#contato`)
- WhatsApp QR Code for quick desktop-to-mobile scanning.
- Social media links (IG / TikTok).
- Physical address.
- Standard copyright.
